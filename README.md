Porto Sol is an original open-world crime game built for make.fun's Make GTA 6 bounty: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and run five story missions for fixer Mara Voss — with traffic, pedestrians, combat, a HUD with minimap, saves, and synthesized sound, all offline from static files.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
